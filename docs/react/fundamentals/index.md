# Fundamentals

**Purpose of this section**: general programming concepts and paradigms that aren't tied to a
specific language or framework — the kind of thing that applies whether you're writing React,
Java, or SQL.

## What should be documented here

- Programming paradigms (declarative vs imperative, OOP vs functional, etc.)
- Core CS concepts (data structures, complexity, design patterns)
- Cross-cutting ideas that show up across every stack you learn

## Suggested organization

- One Markdown page per concept
- Cross-link to the language/framework page where you saw the concept in practice (e.g. link from
  here to `react/` when a concept shows up in JSX)
