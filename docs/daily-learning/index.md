# Daily Learning

**Purpose of this section**: a running log of what I learned, day by day.

## What should be documented here

- Short daily or weekly entries
- Links back to the relevant topic page when an entry expands into a full note

## Suggested organization

- One Markdown page per day or per week (e.g. `2026-07-17.md`)
- Keep entries short — expand into a topic folder elsewhere once a subject grows
